# APK de desarrollo — Correlativas Demo DEV

Descargá `correlativas-demo-dev-0.1.0.apk` con **Download raw** y abrilo en tu Android.
Versión 0.1.0-demo, identificador `com.correlativas.demo.dev`, Android 7.0/API 24+.
Solo datos ficticios y firma debug. No necesita Internet ni una cuenta.
No es un APK de producción y no se instala en iPhone.

La guía de instalación, pruebas físicas y reporte de errores está en
[la documentación de esta etapa](../README.md).

Archivos adicionales:

- `SHA256SUMS`: integridad del APK.
- `verification.json`: firma, paquete, assets y ausencia de permiso de Internet.
- `test-results.json`: pruebas ejecutadas y límites de validación.

No se incluyen claves privadas, certificados de producción ni configuración de Firebase.
