# Descargar la demo para revisión

El ZIP conserva exactamente la demo ya generada: no se reconstruyó ni cambió el diseño.

1. Abrí `correlativas-mobile-demo.zip` en esta carpeta desde GitHub.
2. Usá **Download raw / Descargar archivo** para guardar el ZIP en tu computadora.
3. Extraelo y abrí `Correlativas-demo.html` en Chrome, Edge o Firefox.

No necesita instalar dependencias, iniciar un servidor, autenticarse ni conectarse a Internet.
Todos los datos son ficticios; los cambios se pierden al recargar.
Algunos visores de archivos de celulares no ejecutan JavaScript: probar en un navegador de escritorio.
